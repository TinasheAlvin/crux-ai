# Vhona AI marketing site

Static landing page (`index.html`) and `stone.jpg`, the fitted-granite background. No build step.

Enable Pages → **Deploy from a branch** → branch `main` → folder `/docs`.

The site URL will be https://tinashealvin.github.io/vhona-ai/ after the GitHub repository is renamed from `crux-ai` to `vhona-ai`. Until that rename, GitHub Pages still serves https://tinashealvin.github.io/crux-ai/.

Cloudflare Pages may still answer at https://crux-ai.pages.dev until the Pages project (and any custom domain) is updated. That hostname is separate from this `/docs` folder.
